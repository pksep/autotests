# Еженедельная проверка: Архив

## Область проверки

Страница: **Архив**

Маршрут: `/archive`

Проверяется только основная страница списка архива.

## Что есть на странице

- Фильтр **Тип сущности**
- Счетчик **Кол-во**
- Поиск: **Поиск по обозначению, артиклу и наименованию**
- Таблица архива с колонками:
  - **№**
  - **Обозначение**
  - **Артикул**
  - **Наименование**
  - действие истории запросов

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **Архив**. | Страница открывается с правильным заголовком, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить фильтр **Тип сущности**. | Фильтр виден и показывает активный тип сущности, например **Изделие**. | Не выполнено |  |
| 3 | Изменить тип сущности, если безопасно. | Таблица архива обновляется по выбранному типу сущности или показывает понятное пустое состояние. | Не выполнено |  |
| 4 | Проверить счетчик. | **Кол-во** видно и является числом для активного типа сущности. | Не выполнено |  |
| 5 | Проверить поле поиска. | Видно **Поиск по обозначению, артиклу и наименованию**. | Не выполнено |  |
| 6 | Выполнить поиск по обозначению. | Остаются подходящие архивные строки или появляется понятное пустое состояние. | Не выполнено |  |
| 7 | Выполнить поиск по артикулу или наименованию. | Остаются подходящие архивные строки или появляется понятное пустое состояние. | Не выполнено |  |
| 8 | Очистить поиск. | Строки архива возвращаются для активного типа сущности. | Не выполнено |  |
| 9 | Проверить таблицу архива. | Таблица видна и содержит строки или понятное пустое состояние. | Не выполнено |  |
| 10 | Проверить обязательные заголовки. | Есть **№**, **Обозначение**, **Артикул**, **Наименование**. | Не выполнено |  |
| 11 | Проверить качество данных строк. | Обозначение, артикул и наименование читаются. Знаки вопроса допустимы только если это ожидаемые старые данные. | Не выполнено |  |
| 12 | Использовать действие истории, если оно видно. | История открывается или показывает понятное пустое состояние, не блокируя таблицу. | Не выполнено |  |
| 13 | Обновить страницу. | Фильтр типа сущности, счетчик, поиск и таблица архива перезагружаются. | Не выполнено |  |
| 14 | Проверить макет. | Длинные названия архивных позиций читаются, колонки таблицы не перекрываются. | Не выполнено |  |

## Критерии успешной проверки

- Страница архива успешно загружается.
- Фильтр типа сущности, счетчик, поиск и таблица видны.
- Поиск работает и очищается.
- Строки архива читаются.
- Нет зависших загрузчиков, заблокированных окон и видимых технических ошибок.
