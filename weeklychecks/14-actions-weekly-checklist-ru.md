# Еженедельная проверка: Действия

## Область проверки

Страница: **Действия**

Маршрут: `/actions`

Заголовок основной области: **История изменений**

Проверяется только страница истории изменений.

## Что есть на странице

- Контролы диапазона дат
- Фильтр **Сотрудники**
- Фильтр **Тип сущности**
- **Сбросить**
- Таблица истории действий с колонками:
  - **Дата и время**
  - **Сотрудник**
  - **Тип сущности**
  - **Индетификатор сущности**
  - **Действие**

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **Действия**. | Страница открывается с **История изменений**, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить диапазон дат. | Начальная и конечная даты видны и показывают ожидаемый текущий период. | Не выполнено |  |
| 3 | Открыть календарь начальной даты. | Календарь открывается и закрывается без блокировки страницы. | Не выполнено |  |
| 4 | Открыть календарь конечной даты. | Календарь открывается и закрывается без блокировки страницы. | Не выполнено |  |
| 5 | Проверить фильтр **Сотрудники**. | Фильтр виден и показывает **Все** или выбранного сотрудника. | Не выполнено |  |
| 6 | Проверить фильтр **Тип сущности**. | Фильтр виден и показывает **Все** или выбранный тип сущности. | Не выполнено |  |
| 7 | Изменить фильтр сотрудника, если безопасно. | Таблица обновляется по выбранному сотруднику или показывает понятное пустое состояние. | Не выполнено |  |
| 8 | Изменить фильтр типа сущности, если безопасно. | Таблица обновляется по выбранному типу сущности или показывает понятное пустое состояние. | Не выполнено |  |
| 9 | Проверить **Сбросить**. | Кнопка видна; становится активной после изменения фильтров и сбрасывает фильтры при нажатии. | Не выполнено |  |
| 10 | Проверить таблицу истории. | Таблица видна и содержит строки или понятное пустое состояние. | Не выполнено |  |
| 11 | Проверить обязательные заголовки. | Есть **Дата и время**, **Сотрудник**, **Тип сущности**, **Индетификатор сущности**, **Действие**. | Не выполнено |  |
| 12 | Проверить дату и время в строках. | Значения имеют единый формат, например `14.04.2026 15:31:13`. | Не выполнено |  |
| 13 | Проверить сотрудников в строках. | Имена сотрудников читаются или поле намеренно пустое для системных действий. | Не выполнено |  |
| 14 | Проверить типы сущностей. | Типы сущностей читаются: изделие, сборка, задача на отгрузку, элемент заказа на склад, отметка о выполнении и т.п. | Не выполнено |  |
| 15 | Проверить идентификаторы сущностей. | Идентификаторы читаются и не заменены техническими значениями. | Не выполнено |  |
| 16 | Проверить текст действия. | Описания действий понятны и не содержат `undefined`, `null` или сломанного текста. | Не выполнено |  |
| 17 | Обновить страницу. | Диапазон дат, фильтры и таблица истории перезагружаются. | Не выполнено |  |
| 18 | Проверить макет. | Колонки таблицы читаются, длинный текст действия не перекрывает важные данные. | Не выполнено |  |

## Критерии успешной проверки

- **История изменений** успешно загружается.
- Диапазон дат, фильтр сотрудников, фильтр типа сущности и кнопка сброса видны.
- Заголовки и строки таблицы истории читаются.
- Фильтры обновляют таблицу и сбрасываются.
- Нет зависших загрузчиков, заблокированных календарей и видимых технических ошибок.
