# Еженедельная проверка: База контактов

## Область проверки

Страница: **База контактов**

Маршрут: `/contactbase`

Проверяется только основная область страницы.

## Что есть на странице

- Разделы фильтров:
  - **По типу**
  - **По особенностям**
  - **По компании**
- Элементы управления: **Сортировать по дате создания**, **Фильтр по отметке**, **Показать мои**, **Выбрать**
- Поиск: **Поиск по ФИО**
- Колонки таблицы контактов:
  - **ФИО**
  - **Компания**
  - **E-mail**
  - **Тип**
  - **Дата создания**
  - действие истории запросов
- Кнопки действий: **Создать**, **Архив**

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **База контактов**. | Страница открывается с правильным заголовком, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить разделы фильтров. | Видны фильтры по типу, особенностям и компании. | Не выполнено |  |
| 3 | Проверить элементы особенностей. | Видны сортировка по дате, фильтр по отметке и **Показать мои**; **Показать мои** может быть неактивна. | Не выполнено |  |
| 4 | Проверить фильтр по компании. | Видна кнопка **Выбрать** для фильтрации по компании. | Не выполнено |  |
| 5 | Проверить таблицу контактов. | Таблица видна и содержит строки или понятное пустое состояние. | Не выполнено |  |
| 6 | Проверить заголовки. | Есть **ФИО**, **Компания**, **E-mail**, **Тип**, **Дата создания**. | Не выполнено |  |
| 7 | Выполнить поиск по ФИО. | **Поиск по ФИО** фильтрует контакты или показывает понятное пустое состояние. | Не выполнено |  |
| 8 | Очистить поиск. | Список контактов возвращается для активных фильтров. | Не выполнено |  |
| 9 | Изменить фильтр по типу, если безопасно. | Таблица обновляется по выбранному типу контакта или показывает понятное пустое состояние. | Не выполнено |  |
| 10 | Использовать фильтр по компании. | Выбор компании открывается и закрывается без блокировки страницы. | Не выполнено |  |
| 11 | Нажать **Сортировать по дате создания**. | Порядок строк меняется или данные обновляются без ошибок. | Не выполнено |  |
| 12 | Нажать **Фильтр по отметке**. | Таблица обновляется и остается доступной. | Не выполнено |  |
| 13 | Выбрать строку контакта. | Строка становится активной, **Архив** становится доступен, если архивирование разрешено. | Не выполнено |  |
| 14 | Проверить **Создать**. | Кнопка видна и активна. Новый контакт в рамках еженедельной проверки не сохранять. | Не выполнено |  |
| 15 | Использовать действие истории, если оно видно. | История открывается или показывает понятное пустое состояние, не блокируя таблицу. | Не выполнено |  |
| 16 | Обновить страницу. | Фильтры, поиск, таблица и действия перезагружаются. | Не выполнено |  |
| 17 | Проверить макет. | ФИО, компании, e-mail и даты читаются. | Не выполнено |  |

## Критерии успешной проверки

- База контактов успешно загружается.
- Фильтры, поиск, таблица и действия видны.
- Поиск по ФИО работает и очищается.
- Фильтры по компании и типу не блокируют страницу.
- Строки контактов читаются и не содержат технических заглушек.
