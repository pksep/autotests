# Еженедельная проверка: База оборудования

## Область проверки

Страница: **База оборудования**

Маршрут: `/baseequipments`

Проверяется только основная область страницы.

## Что есть на странице

- Заголовок отображается как **База Оборудования**
- Три связанные таблицы:
  - **Тип**
  - **Подтип**
  - **Наименование (Марка/Типоразмер)**
- Поиск в каждой таблице: **Поиск по наименованию**
- Кнопки действий: **Создать**, **Создать копированием**, **Редактировать**, **Архив**
- Фильтры/чекбоксы по особенностям в основной области

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **База оборудования**. | Страница открывается с заголовком **База Оборудования**, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить кнопки действий. | **Создать** активно; копирование, редактирование и архив неактивны до выбора позиции. | Не выполнено |  |
| 3 | Проверить таблицу типов. | Таблица видна и содержит категории оборудования. | Не выполнено |  |
| 4 | Проверить таблицу подтипов. | Таблица видна и содержит подтипы оборудования. | Не выполнено |  |
| 5 | Проверить таблицу наименований. | Таблица видна и содержит наименования оборудования. | Не выполнено |  |
| 6 | Проверить заголовки. | Есть **Тип**, **Подтип** и **Наименование (Марка/Типоразмер)**. | Не выполнено |  |
| 7 | Выполнить поиск по типу. | Таблица типов фильтруется или показывает понятное пустое состояние. | Не выполнено |  |
| 8 | Выполнить поиск по подтипу. | Таблица подтипов фильтруется или показывает понятное пустое состояние. | Не выполнено |  |
| 9 | Выполнить поиск по наименованию. | Таблица наименований фильтруется или показывает понятное пустое состояние. | Не выполнено |  |
| 10 | Очистить поиски. | Строки возвращаются во всех трех таблицах. | Не выполнено |  |
| 11 | Выбрать строку типа. | Связанные данные подтипов и наименований остаются читаемыми. | Не выполнено |  |
| 12 | Выбрать строку подтипа. | Таблица наименований обновляется или остается согласованной с выбранным подтипом. | Не выполнено |  |
| 13 | Выбрать строку наименования. | Копирование, редактирование и архив становятся доступны, если ожидается выбор позиции. | Не выполнено |  |
| 14 | Проверить действие истории, если оно видно. | История открывается или показывает понятное пустое состояние, не блокируя страницу. | Не выполнено |  |
| 15 | Проверить **Создать**. | Кнопка видна и активна. Новую запись в рамках еженедельной проверки не сохранять. | Не выполнено |  |
| 16 | Обновить страницу. | Страница перезагружается с таблицами, поиском и действиями. | Не выполнено |  |
| 17 | Проверить макет. | Три таблицы читаются, длинные названия оборудования не перекрывают элементы управления. | Не выполнено |  |

## Критерии успешной проверки

- Страница загружается и показывает три связанные таблицы оборудования.
- Поиск работает и очищается.
- Выбор строк не ломает зависимые данные.
- Состояние кнопок действий корректно до и после выбора позиции.
- Нет видимых технических ошибок, зависших загрузчиков и заблокированных окон.
