# Еженедельная проверка: База материалов

## Область проверки

Страница: **База материалов**

Маршрут: `/basematerials`

Этот чек-лист относится к основной области страницы базы материалов и к первому экрану, который открывается по кнопке **Создать**. Авторизация, боковое меню и сохранение нового материала здесь не проверяются.

## Что есть на странице

На странице есть переключатели категорий:

- **Все**
- **Материалы для деталей**
- **Покупные детали**
- **Расходные материалы**

На странице есть три связанные таблицы материалов:

| Таблица | Примеры обязательных заголовков | Поле поиска |
| --- | --- | --- |
| Тип | **Тип (Тип профиля заготовки)** или **Тип (Категория)** | **Поиск по наименованию** |
| Подтип | **Подтип (Материал заготовки)** или **Подтип (Материал)** | **Поиск по наименованию** |
| Наименование | **Наименование (Марка / типоразмер)** | **Поиск по наименованию** |

Также на странице есть:

- **Фильтровать по отметке**
- **Сортировать по дате создания**
- **Показать мои**
- **Создать**
- **Создать копированием**
- **Редактировать**
- **Архив**

| 17 | Выполнить поиск в таблице типов. | Ввод видимого типа в **Поиск по наименованию** фильтрует таблицу типов или показывает понятное пустое состояние. | Не выполнено |  |

| 25 | Выбрать строку в таблице наименований. | **Создать копированием**, **Редактировать** и **Архив** становятся активными. | Не выполнено |  |
| 26 | Использовать действие истории, если оно видно. | История запросов открывается или показывает понятное пустое состояние, не блокируя страницу. | Не выполнено |  |
| 27 | Нажать **Фильтровать по отметке**. | Таблицы обновляются и остаются доступными. | Не выполнено |  |
| 28 | Нажать **Сортировать по дате создания**. | Порядок данных меняется, данные остаются читаемыми. | Не выполнено |  |

## Критерии успешной проверки

- **База материалов** успешно загружается.
- Все четыре переключателя категорий видны и работают.
- Таблицы типов, подтипов и наименований видны и обновляются при смене категории.
- Поиск работает отдельно в каждой из трех таблиц и очищается.
- Кнопки действий остаются неактивными при выборе типа/подтипа и становятся активными при выборе наименования.
- **Создать** открывает страницу **Создание материала**.
- На странице нет зависших загрузчиков, заблокированных окон, сломанного текста и видимых технических ошибок.
