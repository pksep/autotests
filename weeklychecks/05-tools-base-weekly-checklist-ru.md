# Еженедельная проверка: База инструмента и оснастки

## Область проверки

Страница: **База инструмента и оснастки**

Маршрут: `/basetools`

Проверяется только основная область страницы.

## Что есть на странице

- Переключатели: **Все**, **Инструмент**, **Оснастка**, **Мерительный инструмент**
- Фильтры: **Фильтровать по отметке**, **Сортировать по дате создания**, **Показать мои**
- Три связанные таблицы:
  - **Тип (Инструмента или оснастки)**
  - **Подтип**
  - **Наименование (Марка/Типоразмер)**
- Поиск в каждой таблице: **Поиск по наименованию**
- Кнопки действий: **Создать**, **Создать копированием**, **Редактировать**, **Архив**

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **База инструмента и оснастки**. | Страница открывается с правильным заголовком, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить переключатели. | Видны **Все**, **Инструмент**, **Оснастка**, **Мерительный инструмент**; по умолчанию активен **Все**. | Не выполнено |  |
| 3 | Проверить фильтры. | Видны фильтр по отметке, сортировка по дате создания и **Показать мои**; **Показать мои** может быть неактивна. | Не выполнено |  |
| 4 | Проверить таблицу типов. | Таблица видна и содержит категории инструмента/оснастки. | Не выполнено |  |
| 5 | Проверить таблицу подтипов. | Таблица видна и содержит подтипы инструмента/оснастки. | Не выполнено |  |
| 6 | Проверить таблицу наименований. | Таблица видна и содержит значения **Наименование (Марка/Типоразмер)**. | Не выполнено |  |
| 7 | Переключиться на **Инструмент**. | Таблицы обновляются для инструмента. | Не выполнено |  |
| 8 | Переключиться на **Оснастка**. | Таблицы обновляются для оснастки. | Не выполнено |  |
| 9 | Переключиться на **Мерительный инструмент**. | Таблицы обновляются для измерительного инструмента или показывают понятное пустое состояние. | Не выполнено |  |
| 10 | Выполнить поиск в каждой таблице по видимому значению. | Остаются подходящие строки или появляется понятное пустое состояние. | Не выполнено |  |
| 11 | Очистить каждый поиск. | Строки возвращаются для активного переключателя. | Не выполнено |  |
| 12 | Выбрать строки типа и подтипа. | Зависимые таблицы остаются читаемыми, макет не ломается. | Не выполнено |  |
| 13 | Выбрать строку наименования. | **Создать копированием**, **Редактировать** и **Архив** становятся доступны, если действие ожидается для выбранной позиции. | Не выполнено |  |
| 14 | Нажать **Фильтровать по отметке**. | Таблицы обновляются и остаются доступными. | Не выполнено |  |
| 15 | Нажать **Сортировать по дате создания**. | Порядок строк меняется или данные обновляются без ошибок. | Не выполнено |  |
| 16 | Проверить **Создать**. | Кнопка видна и активна. Новый элемент в рамках еженедельной проверки не сохранять. | Не выполнено |  |
| 17 | Использовать действие истории, если оно видно. | История открывается или показывает понятное пустое состояние, не блокируя страницу. | Не выполнено |  |
| 18 | Обновить страницу. | Страница перезагружается с видимыми переключателями, таблицами, поиском и действиями. | Не выполнено |  |

## Критерии успешной проверки

- Заголовок, переключатели, фильтры и три таблицы видны.
- Поиск работает в таблицах типа, подтипа и наименования.
- Переключатели категорий обновляют данные.
- Состояние кнопок действий корректно меняется при выборе строк.
- Нет зависших загрузчиков, сломанного текста и заблокированных окон.
