# Еженедельная проверка: База техники и инвентаря

## Область проверки

Страница: **База техники и инвентаря**

Маршрут: `/inventary`

Проверяется только основная область страницы.

## Что есть на странице

- Фильтры: **Фильтровать по отметке**, **Сортировать по дате создания**, **Показать мои**
- Три связанные таблицы:
  - **Тип**
  - **Подтип**
  - **Наименование (Марка/Типоразмер)**
- Поиск в каждой таблице: **Поиск по наименованию**
- Кнопки действий: **Создать**, **Создать копированием**, **Редактировать**, **Архив**

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **База техники и инвентаря**. | Страница открывается с правильным заголовком, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить фильтры. | Видны фильтр по отметке, сортировка по дате создания и **Показать мои**. | Не выполнено |  |
| 3 | Проверить начальное состояние кнопок. | **Создать** активно; копирование, редактирование и архив неактивны до выбора позиции. | Не выполнено |  |
| 4 | Проверить таблицу типов. | Таблица видна с заголовком **Тип**, строками или понятным пустым состоянием. | Не выполнено |  |
| 5 | Проверить таблицу подтипов. | Таблица видна с заголовком **Подтип**, строками или понятным пустым состоянием. | Не выполнено |  |
| 6 | Проверить таблицу наименований. | Таблица видна с заголовком **Наименование (Марка/Типоразмер)**, строками или понятным пустым состоянием. | Не выполнено |  |
| 7 | Выполнить поиск в каждой таблице. | Поиск по видимому значению фильтрует результат или показывает понятное пустое состояние. | Не выполнено |  |
| 8 | Очистить каждый поиск. | Данные возвращаются для текущего вида. | Не выполнено |  |
| 9 | Выбрать строки типа и подтипа. | Зависимые данные остаются читаемыми, макет стабилен. | Не выполнено |  |
| 10 | Выбрать строку наименования, если она есть. | Копирование, редактирование и архив становятся доступны, если ожидается выбор позиции. | Не выполнено |  |
| 11 | Нажать **Фильтровать по отметке**. | Таблицы обновляются и остаются доступными. | Не выполнено |  |
| 12 | Нажать **Сортировать по дате создания**. | Данные обновляются или меняют порядок без ошибок. | Не выполнено |  |
| 13 | Проверить **Создать**. | Кнопка видна и активна. Новую запись в рамках еженедельной проверки не сохранять. | Не выполнено |  |
| 14 | Обновить страницу. | Заголовок, фильтры, таблицы, поиск и действия перезагружаются. | Не выполнено |  |
| 15 | Проверить макет. | Пустые состояния и заполненные строки читаются; элементы управления не перекрываются. | Не выполнено |  |

## Критерии успешной проверки

- Страница успешно загружается.
- Таблицы типа, подтипа и наименования видны.
- Пустые состояния понятны, если строк нет.
- Поиск и фильтры не ломают страницу.
- Кнопки действий соответствуют состоянию выбора строки.
