# Weekly Check: Equipment Base

## Scope

Page: **База оборудования**

Route: `/baseequipments`

This checklist covers the main content area only.

## What Is On The Page

- Title shown as **База Оборудования**
- Three linked tables:
  - **Тип**
  - **Подтип**
  - **Наименование (Марка/Типоразмер)**
- Search field in each table: **Поиск по наименованию**
- Action buttons: **Создать**, **Создать копированием**, **Редактировать**, **Архив**
- Filter chips/checkboxes for feature filtering, plus filter behavior visible in the content area

## Pass Criteria

- The page loads and shows the three linked equipment tables.
- Searches work and can be cleared.
- Selection does not break dependent table data.
- Toolbar state is correct before and after item selection.
- No visible technical errors, stuck loaders, or blocked overlays remain.
