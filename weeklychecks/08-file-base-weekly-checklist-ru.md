# Еженедельная проверка: База файлов

## Область проверки

Страница: **База файлов**

Маршрут: `/filebase`

Проверяется только основная область страницы.

## Что есть на странице

- Переключатели: **Все**, **Архив**, **Без связи**, **Без типа**
- Область фильтра: **Фильтрация по типу**
- Поиск: **Поиск по наименованию**
- Колонки таблицы файлов:
  - **№**
  - **Тип**
  - **Наименование**
  - **Дата**
  - **Примечание**
  - действие истории запросов
- Кнопки действий: **Редактировать**, **Присвоить**, **Архив**

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **База файлов**. | Страница открывается с правильным заголовком, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить переключатели. | Видны **Все**, **Архив**, **Без связи**, **Без типа**; по умолчанию активен **Все**. | Не выполнено |  |
| 3 | Проверить таблицу файлов. | Таблица видна и содержит строки файлов или понятное пустое состояние. | Не выполнено |  |
| 4 | Проверить заголовки. | Есть **№**, **Тип**, **Наименование**, **Дата**, **Примечание**. | Не выполнено |  |
| 5 | Проверить поиск. | Поиск по видимому имени файла фильтрует таблицу или показывает понятное пустое состояние. | Не выполнено |  |
| 6 | Очистить поиск. | Список файлов возвращается для активного переключателя. | Не выполнено |  |
| 7 | Переключиться на **Архив**. | Загружаются архивные файлы или понятное пустое состояние. | Не выполнено |  |
| 8 | Переключиться на **Без связи**. | Загружаются файлы без связи или понятное пустое состояние. | Не выполнено |  |
| 9 | Переключиться на **Без типа**. | Загружаются файлы без типа или понятное пустое состояние. | Не выполнено |  |
| 10 | Вернуться на **Все**. | Возвращается обычный список файлов. | Не выполнено |  |
| 11 | Выбрать строку файла. | Строка становится активной, действия становятся доступны, если это ожидается. | Не выполнено |  |
| 12 | Проверить **Редактировать**. | Кнопка становится активной после выбора файла, если редактирование разрешено. | Не выполнено |  |
| 13 | Проверить **Присвоить**. | Кнопка становится активной после выбора файла, если присвоение разрешено. | Не выполнено |  |
| 14 | Проверить **Архив**. | Кнопка становится активной после выбора файла, если архивирование разрешено. | Не выполнено |  |
| 15 | Использовать действие истории, если оно видно. | История открывается или показывает понятное пустое состояние, не блокируя таблицу. | Не выполнено |  |
| 16 | Обновить страницу. | Переключатели, поиск, таблица файлов и действия перезагружаются. | Не выполнено |  |
| 17 | Проверить макет. | Длинные имена файлов и примечания читаются; колонки не перекрываются. | Не выполнено |  |

## Критерии успешной проверки

- База файлов успешно загружается.
- Все четыре переключателя видны и работают.
- Поиск работает и очищается.
- Колонки и строки таблицы файлов читаются.
- Действия со строкой неактивны до выбора и активируются после выбора, если это ожидается.
