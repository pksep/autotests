# Еженедельная проверка главной страницы

## Проверяемая страница

Основная область главной страницы: дашборд **План по операциям**.

Маршрут: `/`

На главной странице есть:

- Заголовок: **План по операциям**
- Две вкладки дашборда:
  - **Металлообработка**
  - **Сборка**
- Карточки операций с количеством, например:
  - **Заготовительная-резка ленточнопильная (286)**
  - **Токарный-ЧПУ (208)**
  - **Листовая резка (129)**
  - **Фрезер-ЧПУ (82)**
- Страницы детализации операции, которые открываются при нажатии на карточку операции.

## Цель проверки

Выполнять эту проверку один раз в неделю, чтобы убедиться, что главный дашборд загружается, показывает актуальные количества по операциям, корректно переключается между вкладками **Металлообработка** и **Сборка**, а также открывает детализацию операции без зависших загрузчиков и проблем с версткой.

## Еженедельный чек-лист

| Область | Что проверить | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| Загрузка главной страницы | Открыть главную страницу после входа в систему. | Центральный дашборд загружается без пустого экрана и без постоянного загрузчика. | Не выполнено |  |
| Заголовок страницы | Проверить заголовок основной области. | Видно **План по операциям**. | Не выполнено |  |
| Видимость вкладок | Проверить вкладки дашборда. | Видны обе вкладки: **Металлообработка** и **Сборка**. | Не выполнено |  |
| Вкладка Металлообработка | Нажать **Металлообработка**. | Загружаются карточки операций металлообработки с читаемыми названиями и числовыми значениями. | Не выполнено |  |
| Вкладка Сборка | Нажать **Сборка**. | Загружаются карточки операций сборки с читаемыми названиями и числовыми значениями либо отображается понятное пустое состояние, если данных нет. | Не выполнено |  |
| Переключение вкладок | Несколько раз переключиться между **Металлообработка** и **Сборка**. | Карточки обновляются корректно; нет дублей, пропавшего контента или зависшего загрузчика. | Не выполнено |  |
| Количество на карточках | Проверить несколько карточек операций. | Количество видно и оно числовое, в формате вроде `(286)`. | Не выполнено |  |
| Текст карточек | Просмотреть названия операций. | Названия читаемые, не обрезаны, не накладываются друг на друга и не заменены техническими значениями `undefined`, `null`, `[object Object]`. | Не выполнено |  |
| Расположение карточек | Проверить сетку карточек на обычном desktop-размере. | Карточки выровнены и по ним удобно нажимать. | Не выполнено |  |
| Ключевые карточки | Записать значения по важным операциям. | Существенные неожиданные изменения по сравнению с прошлой неделей разобраны. | Не выполнено |  |
| Переход по карточке | Нажать карточку операции с ненулевым количеством. | Открывается страница детализации операции. | Не выполнено |  |
| Заголовок детализации | Проверить заголовок страницы детализации операции. | Заголовок начинается с **Операция:** и содержит название выбранной операции. | Не выполнено |  |
| Таблица детализации | Проверить таблицу на странице операции. | Заголовки и строки таблицы загружаются либо отображается понятное пустое состояние. | Не выполнено |  |
| Загрузчик детализации | Посмотреть на страницу операции после открытия. | Любой загрузчик исчезает за приемлемое время. | Не выполнено |  |
| Возврат на дашборд | Вернуться с детализации операции на главную страницу. | Дашборд **План по операциям** снова загружается без повторного входа в систему. | Не выполнено |  |
| Обновление страницы | Обновить главную страницу в браузере. | Дашборд перезагружается, карточки операций снова отображаются. | Не выполнено |  |
| Визуальная проверка | Проверить страницу на визуальные дефекты. | Нет сломанных иконок, обрезанного текста, наложения карточек и видимых технических ошибок. | Не выполнено |  |
| Работа через VPN/медленное соединение | Проверить дашборд в условиях обычного еженедельного подключения. | Страница остается пригодной для работы, даже если загружается медленнее обычного. | Не выполнено |  |
| Скриншот | Сохранить скриншот дашборда. | Скриншот сохранен с датой и окружением для сравнения по неделям. | Не выполнено |  |

## Критерии успешной проверки

- Дашборд **План по операциям** загружается.
- Обе вкладки, **Металлообработка** и **Сборка**, видны и работают.
- Карточки операций показывают читаемые названия и числовые значения.
- Переключение вкладок корректно обновляет дашборд.
- Нажатие на карточку с ненулевым количеством открывает правильную страницу детализации операции.
- Страница детализации операции не заблокирована постоянным загрузчиком.
- Возврат на главный дашборд работает.
