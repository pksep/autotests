# Еженедельная проверка: База компаний

## Область проверки

Страница: **База компаний**

Маршрут: `/companybase`

Проверяется только основная область страницы.

## Что есть на странице

- Разделы фильтров:
  - **По типу**
  - **По особенностям**
  - **По поставке/покупке**
- Элементы управления: **Сортировать по дате создания**, **Фильтр по отметке**, **Показать мои**, **Выбрать**
- Поиск: **Поиск по ИНН и наименованию**
- Колонки таблицы компаний:
  - **ИНН**
  - **Наименование**
  - **Тип компании**
  - **Дата создания**
  - действие истории запросов
- Кнопки действий: **Создать**, **Архив**

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **База компаний**. | Страница открывается с правильным заголовком, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить разделы фильтров. | Видны фильтры по типу, особенностям и поставке/покупке. | Не выполнено |  |
| 3 | Проверить элементы особенностей. | Видны сортировка по дате, фильтр по отметке и **Показать мои**; **Показать мои** может быть неактивна. | Не выполнено |  |
| 4 | Проверить фильтр по поставке/покупке. | Видна кнопка **Выбрать**, открывается выбор при использовании. | Не выполнено |  |
| 5 | Проверить таблицу компаний. | Таблица видна и содержит строки или понятное пустое состояние. | Не выполнено |  |
| 6 | Проверить заголовки. | Есть **ИНН**, **Наименование**, **Тип компании**, **Дата создания**. | Не выполнено |  |
| 7 | Выполнить поиск по ИНН или названию. | **Поиск по ИНН и наименованию** фильтрует компании или показывает понятное пустое состояние. | Не выполнено |  |
| 8 | Очистить поиск. | Список компаний возвращается для активных фильтров. | Не выполнено |  |
| 9 | Изменить фильтр по типу, если безопасно. | Таблица обновляется по выбранному типу компании или показывает понятное пустое состояние. | Не выполнено |  |
| 10 | Нажать **Сортировать по дате создания**. | Порядок строк меняется или данные обновляются без ошибок. | Не выполнено |  |
| 11 | Нажать **Фильтр по отметке**. | Таблица обновляется и остается доступной. | Не выполнено |  |
| 12 | Выбрать строку компании. | Строка становится активной, **Архив** становится доступен, если архивирование разрешено. | Не выполнено |  |
| 13 | Проверить **Создать**. | Кнопка видна и активна. Новую компанию в рамках еженедельной проверки не сохранять. | Не выполнено |  |
| 14 | Использовать действие истории, если оно видно. | История открывается или показывает понятное пустое состояние, не блокируя таблицу. | Не выполнено |  |
| 15 | Обновить страницу. | Фильтры, поиск, таблица и действия перезагружаются. | Не выполнено |  |
| 16 | Проверить макет. | ИНН, наименование, тип компании и дата создания читаются. | Не выполнено |  |

## Критерии успешной проверки

- База компаний успешно загружается.
- Фильтры, поиск, таблица и действия видны.
- Поиск по ИНН/наименованию работает и очищается.
- Фильтры не блокируют страницу.
- Строки компаний читаются и не содержат технических заглушек.
