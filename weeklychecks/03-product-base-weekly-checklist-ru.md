# Еженедельная проверка: База продукции

## Область проверки

Страница: **База продукции**

Маршрут: `/baseproducts`

Заголовок основной области: **База изделий, сборок и деталей**

Этот чек-лист относится только к основной области страницы базы продукции. Авторизация, боковое меню и полные сценарии создания, редактирования и архивации здесь не проверяются.

## Что есть на странице

При осмотре страницы были видны три таблицы базы:

| Таблица | Обязательные заголовки | Поле поиска |
| --- | --- | --- |
| **Изделие** | **Обозначение**, **Артикул**, **Наименование**, действие истории | **Поиск по обозначению, артикулу и наименованию** |
| **Сборочная единица (Тип СБ)** | **Обозначение**, **Наименование**, действие истории | **Поиск по обозначению и наименованию** |
| **Деталь (Тип Д)** | **Обозначение**, **Наименование**, действие истории | **Поиск по обозначению и наименованию** |

Также на странице есть общие элементы управления:

- **Фильтровать по отметке**
- **Сортировать по дате создания**
- **Показать мои**
- **Снято с производства**
- **Создать**
- **Создать копированием**
- **Редактировать**
- **Архив**

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **База продукции**. | Страница открывается на **База изделий, сборок и деталей**, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить наличие трех основных таблиц. | В основной области видны **Изделие**, **Сборочная единица (Тип СБ)** и **Деталь (Тип Д)**. | Не выполнено |  |
| 3 | Проверить счетчики таблиц. | У каждой таблицы видны значения **Кол-во** и **Без операций**, если они предусмотрены. Значения числовые и не пустые. | Не выполнено |  |
| 4 | Проверить заголовки таблицы **Изделие**. | Есть **Обозначение**, **Артикул** и **Наименование**. | Не выполнено |  |
| 5 | Проверить заголовки таблицы **Сборочная единица (Тип СБ)**. | Есть **Обозначение** и **Наименование**. | Не выполнено |  |
| 6 | Проверить заголовки таблицы **Деталь (Тип Д)**. | Есть **Обозначение** и **Наименование**. | Не выполнено |  |
| 7 | Просмотреть первые видимые строки в **Изделие**. | В строках читаются обозначение, артикул и наименование. Нет технических значений `undefined`, `null` или `[object Object]`. | Не выполнено |  |
| 8 | Просмотреть первые видимые строки в **Сборочная единица (Тип СБ)**. | В строках читаются обозначение и наименование. | Не выполнено |  |
| 9 | Просмотреть первые видимые строки в **Деталь (Тип Д)**. | В строках читаются обозначение и наименование. | Не выполнено |  |
| 10 | Выполнить поиск в **Изделие** по видимому обозначению, артикулу или наименованию. | В таблице остаются подходящие результаты или отображается понятное пустое состояние. | Не выполнено |  |
| 11 | Очистить поиск в **Изделие**. | Таблица изделий возвращается к результатам без поиска. | Не выполнено |  |
| 12 | Выполнить поиск в **Сборочная единица (Тип СБ)** по видимому обозначению или наименованию. | В таблице остаются подходящие результаты или отображается понятное пустое состояние. | Не выполнено |  |
| 13 | Очистить поиск в **Сборочная единица (Тип СБ)**. | Таблица сборочных единиц возвращается к результатам без поиска. | Не выполнено |  |
| 14 | Выполнить поиск в **Деталь (Тип Д)** по видимому обозначению или наименованию. | В таблице остаются подходящие результаты или отображается понятное пустое состояние. | Не выполнено |  |
| 15 | Очистить поиск в **Деталь (Тип Д)**. | Таблица деталей возвращается к результатам без поиска. | Не выполнено |  |
| 16 | Проверить кнопки действий до выбора строки. | **Создать** активно. **Создать копированием**, **Редактировать** и **Архив** неактивны. | Не выполнено |  |
| 17 | Выбрать одну строку в **Изделие**. | Строка становится активной, а **Создать копированием**, **Редактировать** и **Архив** становятся доступными. | Не выполнено |  |
| 18 | Выбрать одну строку в **Сборочная единица (Тип СБ)**. | Кнопки действий обновляются для выбранной сборочной единицы. | Не выполнено |  |
| 19 | Выбрать одну строку в **Деталь (Тип Д)**. | Кнопки действий обновляются для выбранной детали. | Не выполнено |  |
| 20 | Нажать **Создать**. | Открывается выбор: **Изделие**, **Сборочную единицу**, **Деталь**. | Не выполнено |  |
| 21 | Закрыть окно выбора без создания записи. | Окно закрывается, таблицы остаются доступными. | Не выполнено |  |
| 22 | Нажать **Фильтровать по отметке**. | Данные и счетчики таблиц обновляются. Страница не зависает и не остается закрытой оверлеем. | Не выполнено |  |
| 23 | Нажать **Сортировать по дате создания**. | Порядок строк меняется, текущие данные остаются читаемыми. | Не выполнено |  |
| 24 | Нажать **Снято с производства**. | Страница показывает записи, снятые с производства, счетчики обновляются. | Не выполнено |  |
| 25 | Вернуть фильтры к обычному рабочему виду. | Три таблицы снова показывают обычные активные данные базы продукции. | Не выполнено |  |
| 26 | Использовать действие истории, если оно видно в строке или области поиска/истории. | История открывается или показывает понятное пустое состояние, не блокируя страницу. | Не выполнено |  |
| 27 | Обновить страницу браузера. | Страница перезагружается и возвращается к **База изделий, сборок и деталей** с тремя видимыми таблицами. | Не выполнено |  |
| 28 | Проверить макет на еженедельном тестовом разрешении. | Три таблицы читаются; длинные названия не перекрывают кнопки, заголовки и соседние таблицы. | Не выполнено |  |

## Критерии успешной проверки

- **База изделий, сборок и деталей** успешно загружается.
- Все три таблицы видны и заполнены или показывают понятное пустое состояние.
- Поиск работает отдельно для изделий, сборочных единиц и деталей.
- Общие фильтры обновляют данные без поломки страницы.
- Кнопки действий неактивны до выбора строки и становятся активными после выбора строки.
- **Создать** открывает выбор **Изделие**, **Сборочную единицу**, **Деталь**.
