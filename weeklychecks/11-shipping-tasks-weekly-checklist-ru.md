# Еженедельная проверка: Задачи на отгрузку

## Область проверки

Страница: **Задачи на отгрузку**

Маршрут: `/issueshipment`

Проверяется только страница списка задач на отгрузку. Полное выполнение заказа на отгрузку здесь не проверяется.

## Что есть на странице

- Контролы диапазона дат
- Активные фильтры, включая **Статус: Заказано** и **Покупатели: Все**
- **Сбросить**
- Поиск: **Поиск по номеру заказа, артиклу или наименованию**
- Кнопки действий: **Создать заказ**, **Редактировать**, **Печать**, **Архив**
- Основная таблица отгрузок с колонками:
  - **№**
  - **Заказ**
  - **Артикул изделия**
  - **Наименование изделия**
  - **Потребность по заказам покупателя**
  - **Кол-во дней**
  - **Осталось дней**
  - **Основание**
  - **Покупатель**
  - **Уровень комплектации**
  - **Статус**
  - плановые/фактические даты и колонки трудоемкости

## Еженедельный чек-лист

| Шаг | Проверка | Ожидаемый результат | Результат | Примечания |
| --- | --- | --- | --- | --- |
| 1 | Открыть **Задачи на отгрузку**. | Страница открывается с правильным заголовком, без зависшего загрузчика. | Не выполнено |  |
| 2 | Проверить диапазон дат. | Начальная и конечная даты видны и открываются без поломки страницы. | Не выполнено |  |
| 3 | Проверить активные фильтры. | Видны фильтры статуса и покупателя, например **Статус: Заказано** и **Покупатели: Все** или актуальные значения. | Не выполнено |  |
| 4 | Проверить **Сбросить**. | Кнопка видна; неактивна, пока фильтры не изменены. | Не выполнено |  |
| 5 | Проверить кнопки до выбора строки. | **Создать заказ** и **Печать** активны; **Редактировать** и **Архив** неактивны до выбора строки. | Не выполнено |  |
| 6 | Проверить таблицу отгрузок. | Таблица видна и содержит строки или понятное пустое состояние. | Не выполнено |  |
| 7 | Проверить обязательные заголовки. | Есть заказ, артикул, наименование, потребность, дни, покупатель, уровень комплектации, статус, плановые даты и трудоемкость. | Не выполнено |  |
| 8 | Выполнить поиск по номеру заказа. | Поиск оставляет подходящие строки или показывает понятное пустое состояние. | Не выполнено |  |
| 9 | Выполнить поиск по артикулу или наименованию изделия. | Поиск оставляет подходящие строки или показывает понятное пустое состояние. | Не выполнено |  |
| 10 | Очистить поиск. | Строки отгрузки возвращаются для активных фильтров и диапазона дат. | Не выполнено |  |
| 11 | Проверить качество данных строк. | Номер заказа, артикул, наименование, количество, покупатель, статус и даты читаются. | Не выполнено |  |
| 12 | Проверить счетчики дней. | **Кол-во дней** и **Осталось дней** числовые и понятные, включая отрицательные значения просрочки. | Не выполнено |  |
| 13 | Проверить уровень комплектации. | **Уровень комплектации** отображается в процентах. | Не выполнено |  |
| 14 | Проверить колонки дат. | Плановая готовность склада, плановая отгрузка и фактическая отгрузка видны и имеют единый формат. | Не выполнено |  |
| 15 | Проверить колонки трудоемкости. | Время МО, сборки и общая трудоемкость читаются и не содержат `NaN`, `undefined` или сломанных пустых значений. | Не выполнено |  |
| 16 | Выбрать строку отгрузки. | **Редактировать** и **Архив** становятся активными. | Не выполнено |  |
| 17 | Нажать **Печать**, если безопасно. | Открывается ожидаемый сценарий печати, страница не блокируется. | Не выполнено |  |
| 18 | Проверить **Создать заказ**. | Кнопка видна и активна. Новый заказ в рамках еженедельной проверки не сохранять. | Не выполнено |  |
| 19 | Использовать действие истории, если оно видно. | История открывается или показывает понятное пустое состояние, не блокируя таблицу. | Не выполнено |  |
| 20 | Обновить страницу. | Фильтры, поиск, кнопки действий и таблица отгрузок перезагружаются. | Не выполнено |  |
| 21 | Проверить макет. | Широкая таблица прокручивается и читается; длинные имена покупателей и изделий не скрывают критичные колонки. | Не выполнено |  |

## Критерии успешной проверки

- Страница задач на отгрузку успешно загружается.
- Диапазон дат, фильтры, поиск и кнопки действий видны.
- Колонки и значения таблицы отгрузок читаются.
- Поиск работает и очищается.
- Выбор строки активирует редактирование и архивирование.
- Нет зависших загрузчиков, заблокированных окон и видимых технических ошибок.
