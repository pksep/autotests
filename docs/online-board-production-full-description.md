# Онлайн табло по ПЗ

## 1. Обзор
**Название:** `Онлайн табло по ПЗ`

## 2. Разбор Интерфейса

> Копия с актуализированными описаниями элементов тура.

### Элементы интерфейса
| Название / Элемент | Описание |
| :--- | :--- |
| **Онлайн табло по ПЗ** | Страница предназначена для оперативного контроля производственных заданий и связанных с ними позиций. В таблице отображаются ПЗ, даты выполнения, состав изделий или деталей, заказанные количества, готовность, маршрут операций и расчетное время выполнения. Данные можно отфильтровать, переключить по типу производства, настроить состав колонок и вывести в печатную форму. |
| **Фильтр по дате** | Позволяет выбрать диапазон дат, по которому будет отфильтрована таблица. В режиме «Сборка» фильтр относится к дате начала работ, а в режиме «Металлообработка» - к требуемому времени готовности. После выбора диапазона список ПЗ и позиций обновляется с учетом выбранных границ. |
| **Фильтр по сотрудникам** | Фильтрует данные по исполнителям. Можно выбрать одного или нескольких сотрудников; в списке приоритетно показываются сотрудники подразделения, соответствующего текущему типу производства: металлообработка или сборка. При очистке фильтра таблица снова показывает данные без ограничения по сотруднику. |
| **Тип операции** | Ограничивает таблицу позициями, в маршруте которых есть выбранные типы технологических операций. Список операций загружается для текущего типа производства, поэтому при переключении между «Металлообработкой» и «Сборкой» набор доступных операций может меняться. |
| **Готовность к комплектации** | Доступно в режиме «Сборка». Включает отбор только тех позиций, которые готовы к передаче на комплектацию, и показывает счетчик таких позиций рядом с названием фильтра. Если готовых к комплектации позиций нет, таблица очищается для этого отбора. |
| **Фильтр по заказам** | Позволяет отобрать позиции по связанным заказам. Внутри фильтра можно выбрать тип заказа, например покупательский или складской, а затем указать конкретные заказы. При выборе заказа таблица показывает только позиции, относящиеся к этому заказу. |
| **Фильтр по родителям** | Фильтрует позиции по родительским изделиям, сборочным единицам и деталям. Для металлообработки доступен выбор деталей, потому что деталировка участвует в производственной цепочке этого режима. Выбранные объекты передаются в фильтр как отдельные списки изделий, СБ и деталей. |
| **Фильтр по ПЗ** | Позволяет выбрать конкретное производственное задание и отобразить в таблице связанные с ним позиции. В раскрытом блоке есть кнопка выбора ПЗ и возможность сбросить выбранное значение. После выбора фильтр закрывается, а таблица обновляется по выбранному ПЗ. |
| **Конфигурация таблицы** | Открывает панель настройки отображаемых колонок. В панели можно выбрать, какие столбцы должны быть видны в таблице, сохранить конфигурацию и затем работать с таблицей в сокращенном или расширенном виде без изменения самих данных. |
| **Тип производства** | Переключает страницу между режимами «Металлообработка» и «Сборка». От выбранного режима зависят доступные фильтры, список операций, набор отображаемых колонок и часть логики расчета данных. При переключении таблица перезагружается, а тур показывает только релевантные для текущего режима шаги. |
| **Поиск** | Выполняет поиск по обозначению и наименованию позиции. После ввода строки и подтверждения поиска таблица перезагружается с первой страницы и показывает только совпадающие детали, изделия или сборочные единицы. Поле поддерживает историю выбора поисковых значений. |
| **Действия** | Меню действий для строки таблицы. В строке производственного задания меню открывает связанное ПЗ, а в строке позиции позволяет перейти к связанным заказам. Меню используется как быстрый доступ к деталям без перехода со страницы онлайн-табло. |
| **№** | Порядковый номер группы производственного задания в текущей выдаче таблицы. Номер формируется на клиенте при подготовке строк и помогает ориентироваться в списке после фильтрации, поиска или подгрузки следующих записей. |
| **Номер ПЗ** | Идентификатор производственного задания, к которому относятся вложенные строки с деталями, изделиями или сборочными единицами. Значение объединяет группу строк, поэтому по нему удобно понять, какие позиции входят в одно ПЗ. |
| **Дата выполнения** | Дата выполнения производственного задания. Она отображается на уровне группы ПЗ и показывает плановый срок, к которому задание должно быть выполнено. Дата используется для контроля сроков и сопоставления с расчетными датами по позициям. |
| **Действия (ПЗ)** | Отдельное меню действий в строках позиций внутри производственного задания. Через него можно открыть связанные заказы по выбранной позиции и проверить, откуда сформирована потребность или заказанное количество. |
| **Изображение** | Отображает изображение, фотографию или чертеж позиции, если для сущности задан файл. Используется для визуальной идентификации детали, изделия или сборочной единицы прямо в таблице без открытия карточки. |
| **Обозначение** | Конструкторское или производственное обозначение позиции. Это основной идентификатор детали, изделия или сборочной единицы в производственной документации; по нему также работает поиск на странице. |
| **Наименование** | Название позиции. Ячейка кликабельна: в режиме металлообработки открывается карточка детали, а в режиме сборки - карточка СБ или изделия в зависимости от типа позиции. В ячейке также могут отображаться служебные признаки, например внимание, описание или снятие с производства. |
| **Тип** | Доступно в режиме «Сборка». Показывает тип позиции: `СБ` для сборочной единицы или `ИЗД` для изделия. Колонка помогает быстро отличить уровень объекта в сборочной структуре. |
| **Начало работ** | Доступно в режиме «Сборка». Показывает дату и время начала работ по позиции. Ячейка может подсвечиваться и показывать предупреждение, если старт работ слишком ранний, запаздывает или конфликтует с плановой датой первой операции. |
| **Требуемое время готовности** | Показывает плановое время готовности позиции из производственного графика. Ячейка кликабельна: по ней можно открыть связанную сущность, которая определяет требуемую дату, например ПЗ, родительскую позицию, отгрузку или складской заказ. |
| **Расчётная дата изготовления** | Показывает расчетную дату, когда позиция должна быть изготовлена по данным производственного маршрута. Расчет строится от времени начала работ и длительности операций; ячейка подсвечивается, если расчетная дата выходит за требуемое время готовности, есть некорректные даты операций или у операций не заполнено основное время. |
| **Дата плановой готовности склада** | Показывает дату, к которой склад ожидает готовность позиции. Значение берется из складской потребности по изделию, сборочной единице или детали и помогает сопоставить производственный график с датой, необходимой для дальнейшего обеспечения склада. |
| **Дата плановой отгрузки** | Показывает дату связанной отгрузки, если позиция привязана к актуальной отгрузке. Если отгрузка не найдена, в ячейке отображается прочерк. Колонка помогает сверить производственные сроки с ожидаемым сроком передачи готовой продукции. |
| **Заказано по ПЗ** | Количество позиции, заказанное в рамках текущего производственного задания. Значение берется для конкретной строки внутри ПЗ и показывает, какой объем этой позиции относится именно к текущему заданию. |
| **Заказано по всем ПЗ** | Суммарное количество этой позиции, заказанное по всем производственным заданиям. Колонка помогает сравнить текущую потребность по одному ПЗ с общим производственным объемом по той же позиции. |
| **Заказано (Всего)** | Общее количество позиции на производстве для строки таблицы. В интерфейсе колонка подписана как «Заказано на производстве»; она показывает общий объем, который используется при расчете времени и контроле выполнения. |
| **Готово к комплектации** | Доступно в режиме «Сборка». Показывает количество позиции, которое уже доступно для комплектации. Значение помогает понять, можно ли передавать позицию дальше в сборочный процесс и сколько единиц готово к использованию. |
| **Количество операций** | Показывает количество операций в технологическом маршруте выбранной позиции. Ячейка кликабельна: по нажатию открывается производственный путь для металлообработки или сборки, где можно посмотреть последовательность операций подробнее. |
| **Операции** | Отображает список операций маршрута по позиции. Для каждой операции выводятся данные о количестве, выполненном количестве, времени исполнения, расчетной дате, основном времени и признаках корректности. При клике по операции открывается модальное окно операции по ПЗ, если позиция действительно заказана в производственном задании. |
| **Время выполнения - 1 шт** | Расчетное время изготовления одной единицы позиции. Суммируется подготовительное время операций и операционное время на одну штуку, включая вспомогательное и основное время. Значение помогает оценить трудоемкость одной единицы без учета всего заказанного объема. |
| **Время выполнения - Все** | Расчетное время изготовления всего количества по ПЗ. В интерфейсе колонка подписана как «Все по ПЗ»; расчет учитывает количество по операциям и показывает полную трудоемкость выполнения позиции в рамках производственного задания. |
| **Время выполнения - Осталось** | Расчетное оставшееся время по ПЗ. В интерфейсе колонка подписана как «Осталось на ПЗ»; значение считается по невыполненному количеству операций и показывает, сколько времени еще требуется для завершения работ. |
| **Печать** | Формирует печатную версию текущего состояния онлайн-табло. При печати скрываются служебные элементы управления, поиск, чекбоксы и итоговая строка, а таблица выводится в формате, пригодном для просмотра или печати. |
